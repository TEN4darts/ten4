プライバシーポリシー

施行日: 2026年10月11日 / 運営者: TEN4

1. 概要

TEN4 Uploader（以下「本アプリ」）は、チャンネル運営者本人（TEN4）が自分の Mac 上でのみ使用する非公開のツールです。他のユーザーは存在せず、一般向けの登録もありません。本アプリは YouTube API Services を利用しています。

2. 利用する Google / YouTube の機能

本アプリは YouTube Data API v3 の videos.insert と videos.update を使い、運営者自身の完成済み動画を運営者自身の YouTube チャンネルへアップロードし、タイトル、説明文、タグ、公開設定、公開予約日時（status.publishAt）を設定します。利用するスコープは次の 1 つです。

https://www.googleapis.com/auth/youtube.upload

3. 取り扱うデータ

  • OAuth トークンは、運営者の Mac 内にのみ保存されます。
  • 動画ファイルとそのメタデータ（タイトル、説明文、タグ、公開設定、公開予約日時）は、YouTube にのみ送信されます。
  • データを販売することはなく、第三者と共有することもありません。
  • 本ウェブサイトでは、アクセス解析ツールや Cookie を使用していません。

4. アクセス権の取り消し

Google アカウントに付与したアクセス権は、いつでも次のページから取り消せます。
https://myaccount.google.com/permissions

5. YouTube および Google の規約

本アプリは YouTube API Services を利用しています。利用者は YouTube 利用規約および Google プライバシーポリシーに拘束されます。

  • YouTube 利用規約 (YouTube Terms of Service)
  • Google プライバシーポリシー (Google Privacy Policy)

English

Privacy Policy

Effective date: October 11, 2026 (2026年10月11日) / Operator: TEN4

1. Overview

TEN4 Uploader (the "App") is a private tool run only by the channel owner (TEN4) on their own Mac. There are no other users and no public sign-up. The App uses YouTube API Services.

2. Google / YouTube features used

The App uses the YouTube Data API v3 methods videos.insert and videos.update to upload the owner's own finished videos to the owner's own YouTube channel and to set the title, description, tags, privacy status and scheduled publish time (status.publishAt). The only scope used is:

https://www.googleapis.com/auth/youtube.upload

3. Data handling

  • OAuth tokens are stored locally on the owner's Mac only.
  • Video files and their metadata (title, description, tags, privacy status, scheduled publish time) are sent only to YouTube.
  • No data is sold, and no data is shared with third parties.
  • This website uses no analytics and no cookies.

4. Revoking access

Access granted to your Google account can be revoked at any time at:
https://myaccount.google.com/permissions

5. YouTube and Google policies

The App uses YouTube API Services. By using it, you are bound by the YouTube Terms of Service and the Google Privacy Policy.

  • YouTube Terms of Service
  • Google Privacy Policy
