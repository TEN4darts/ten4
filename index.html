TEN4

TEN4 is a darts pro and engineer who posts beginner darts tip Shorts on YouTube and TikTok.

About TEN4 Uploader

TEN4 Uploader is a private tool run only by the channel owner on their own Mac. It uploads the owner's own finished videos to the owner's own YouTube channel and sets the title, description, tags, privacy status and scheduled publish time, using the YouTube Data API v3. It is not offered to other users and has no public sign-up.
